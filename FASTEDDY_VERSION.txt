# Divergence from upstream v5.0.1 as of 2026-08-19: ONE feature, ioLPDMmode.
#
#   59f0472  ioLPDMmode: lean 16-bit output for offline Lagrangian dispersion
#   692a3cd  Fix ioLPDMmode: rho must be processed; packed range must avoid the fill value
#   159c855  ioLPDMfullFrq: interleave a restartable full dump into lean output
#
# One optional parameter, defaulting to 0 = upstream behaviour, so the diff is inert unless
# asked for. It writes only the fields a backward LPDM reads and CF-packs the 3-D
# prognostics to 16 bit: a 30-min window at 5 s goes from 61 GB to 15.4 GB at the 24 m grid.
# The resulting files are NOT restartable (rho and pressure are absent by construction).
#
# The kegonsa branch is currently byte-identical to upstream v5.0.1. All build
# customization for this project (sm_89, include/library paths) is applied via
# make command-line overrides in docker/build_fasteddy.sh, NOT by editing the
# FastEddy Makefile. This keeps the fork's diff against upstream empty so that
# pulling NCAR bugfixes stays conflict-free, and so that the first real commit
# on kegonsa is a genuine physical or numerical change.
#
# A vertical-subset (k-range) limit remains possible if storage ever binds again, but
# ioLPDMmode already clears the Stage 3 gate by a factor of two, so it has not been needed.

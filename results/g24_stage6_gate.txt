  PRED-LES uses the LES's OWN crosswind-integrated footprint in place of
  Kljun's, so a gap between PRED-Klj and PRED-LES is the near-field difference
  between the two footprints, while a gap between PRED-LES and MEASURED would
  be an attribution error. Ratios are quoted as well, being the more robust
  comparison at chords of a few grid cells:

    wN / wE :  predicted    89.5x   measured   215.0x
    wN / wS :  predicted     2.8x   measured     3.5x
    wS / wE :  predicted    32.2x   measured    60.8x

  The measured swing EXCEEDS the predicted one in every pair, and in the same
  direction each time: the LES puts less mass in the near field than Kljun does
  (peak 270 m against 150 m), so a patch that only reaches 65-146 m upwind loses
  more than Kljun says it should. Sign and ordering both hold.

  The achieved surface winds are backed ~24 deg from the geostrophic forcing by
  Ekman turning, so none of these is a due N/S/E/W case. The prediction uses the
  ACHIEVED direction, which is why it is a fair comparison.
